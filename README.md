Este projeto apresenta uma análise de dados do e-commerce Olist, com foco em vendas, comportamento de clientes e performance de sellers.

O objetivo é transformar dados brutos em insights relevantes para apoiar decisões de negócio.

Objetivo:

Desempenho de vendas (receita, pedidos e ticket médio)
Distribuição geográfica dos pedidos
Performance dos sellers
Taxa de churn e possíveis causas

Ferramentas:
MySQL (extração dos dados)
Python (Pandas) para limpeza e transformação
Power BI para visualização
DAX para criação de métricas
Modelagem de dados

Principais análises:
Receita total e evolução ao longo do tempo
Ticket médio (AOV)
Receita e pedidos por estado
Análise de sellers (volume, receita, churn)
Scatter plot para identificação de padrões de sellers

Insights:
A receita está concentrada em poucos sellers
A maioria dos sellers possui baixo volume de pedidos (long tail)
Diferenças regionais impactam o tempo de entrega

Observações:
Foram identificados pedidos marcados como entregues sem data de entrega
Esses casos foram tratados nas análises logísticas
